CSV-Datei hochladen und einlesen

Wähle den Standort und die Logger-ID in deiner Datei. Große Dateien werden in kleinen Blöcken übertragen und anschließend auf dem Server ausgewertet.

Deine CSV-Dateien lokal einlesen

  1. Lege deine Dateien im Projektordner unter daten ab.
  2. Benenne sie wald1.csv, wald2.csv und lichtung.csv, oder passe die Pfade in geraete.json an.
  3. Prüfe dort die Logger-ID jedes Geräts. Auch drei Dateien mit derselben ID lassen sich getrennten Standorten zuordnen.
  4. Klicke auf „CSV-Dateien einlesen“. Der Import arbeitet im Hintergrund.

Erwartetes Format wie bei deinem Loggerexport: Zeitstempel, Geräte-ID, Telegrammfelder. Semikolon, Tabulator und Komma werden erkannt. Echo-Zeilen anderer IDs werden übersprungen.
